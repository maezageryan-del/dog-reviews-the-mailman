## How it runs

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. It asserts the entry is 1–200 characters and not only whitespace.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
